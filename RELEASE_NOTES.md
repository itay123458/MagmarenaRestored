## Magmarena Restored 0.1.0

Restores the old Magmarena entrance in Forest for private and modded private rooms, with the original arena and ball game controls.

- Reconnected tunnel and two-way travel.
- Fixed dark, patchy arena lighting and excessive tunnel brightness.
- Matched the doorway frame to Forest lighting.
- Removed the unused outside sign, blank promotional board, and added ramp.
- Tested with two players in a private room.

Requires Windows/Steam Gorilla Tag build **26061329**, **BepInEx 5**, and a **PUN** private room. All players, including the host, need the mod.

Extract `MagmarenaPrivate-0.1.0.zip` into the game folder while the game is closed. The DLL should be at `BepInEx/plugins/MagmarenaPrivate/MagmarenaPrivate.dll`. Remove any older renamed copy first.

Late joins and host changes have not been separately verified. This version disables itself on unsupported game builds.

Contains the plugin, README, and license. No game assets or dependencies are included.
